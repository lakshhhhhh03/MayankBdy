# Cookie 🍪 Birthday Surprise — merged edition

## Run
Open `index.html` in a browser, or upload the entire folder to any static website host. Keep `Images/`, `assets/`, CSS and JS files in their current locations.

## Experience
- Starts with the animated birthday greeting addressed to Cookie 🍪.
- Use **Open Your Secret Birthday Gift 🎁** to continue into the Secret Birthday Gift experience.
- The original Shinchan-themed verification, teaser, gifts, memories, cake and letter interactions are retained.
- Background song uses the supplied YouTube video. Browsers may block autoplay with sound; tap **Play song** if needed. Internet is required for the YouTube audio and online fonts.

This is a merged static website; no server-side setup is required.
